Prim's Algorithm in C
Description

A C program that uses Prim's Algorithm to find the Minimum Spanning Tree (MST) and minimum construction cost for connecting four cities.

Cities and Road Costs
City 1 - City 2: 10
City 1 - City 3: 6
City 1 - City 4: 5
City 2 - City 4: 15
City 3 - City 4: 4
Algorithm

Prim's Algorithm selects the lowest-cost road that connects a visited city to an unvisited city until every city is connected.

How to Run

Compile using GCC:

Run on Linux or macOS:

./prim
